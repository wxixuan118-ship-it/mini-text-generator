What is a small caps font?

It replaces lowercase letters with capital letters drawn at roughly the height of a lowercase x. The result reads as uppercase but sits quietly in a line of text instead of shouting — which is why typographers have used it for centuries in book headings, author names, acronyms and the opening line of a chapter.

True small capitals are drawn by the type designer and switched on through an OpenType feature. What most people find online is a different thing wearing the same name: a set of Unicode characters that happen to look like small capitals. Those characters come from the Phonetic Extensions block, where they were added so linguists could write phonetic transcriptions. Because they are characters rather than formatting, they can be pasted into a bio or a username and keep their shape.

How to use real small caps in Word, Docs, CSS and design tools

  1. Microsoft Word: select the text and press Ctrl+Shift+K, or open the Font dialog and tick “Small caps”. The letters stay ordinary letters, so spell-check and search still work.
  2. CSS on the web: write font-variant-caps: small-caps. Browsers synthesise the shapes when the font has none, and use the designer's real ones when it does — see the font-variant-caps reference.
  3. Figma, Illustrator and InDesign: look for “Small Caps” under OpenType features in the type panel. Only fonts that actually ship the feature will change.
  4. Google Docs: there is no built-in setting, so paste Unicode small caps from the converter above — the one case where the copy-paste trick is genuinely the better answer.

Small caps font FAQ

Is a small caps font actually a font?

It depends which one you mean. In typography it is a real font feature: the designer draws a second set of capitals at lowercase height, and software switches to them. The style people search for online is something else — a set of Unicode characters that look like small capitals and can be pasted anywhere. This page covers both.

Why does the letter x look like a normal x?

Unicode never encoded a small capital X, so there is nothing to substitute. Every other letter a–z has a small capital form. In most typefaces a lowercase x is already the same shape as a capital X, so it blends in and almost nobody notices.

Will small caps work in my Instagram bio?

The Unicode version will, because it is plain text. A real OpenType font feature will not — Instagram has no font picker, and any formatting you apply elsewhere is stripped when you paste. Use the converter on this page for anything you intend to paste into a social profile.

How do I turn on real small caps in Word or Google Docs?

In Microsoft Word, select the text and press Ctrl+Shift+K (Cmd+Shift+K on a Mac), or tick “Small caps” in the Font dialog. Google Docs has no built-in option, so people usually paste Unicode small caps instead. On the web, use the CSS declaration font-variant-caps: small-caps.

Should I use small caps in a username people search for?

No. Unicode small capitals are different code points from a–z, so a name written in them will not match a search for the plain spelling. Keep your handle in normal letters and use small capitals in your display name or bio instead.

Do small capitals work on every device?

Almost always. The characters come from the Phonetic Extensions block, which every modern phone, desktop and browser font covers. Very old systems and a few game clients may show empty boxes, so paste a short test string before using it somewhere permanent.
