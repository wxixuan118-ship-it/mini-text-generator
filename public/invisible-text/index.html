Invisible Text ⬜

Invisible text is a real character that renders as nothing. Ordinary spaces get trimmed by most sites, so to send an empty message, hold a blank username or add spacing a form will not strip, you need a character that is blank rather than a space. Pick how many you need below, copy, and paste. Each of the eight has its own quirks, listed underneath.

Which invisible character works where

No single blank works everywhere, which is why the tool lists eight rather than one. This table is the short version of where each one holds up.

How to copy invisible text

  1. Pick how many characters you need. One is enough for an empty message; several in a row make a visible indent.
  2. Click “Copy” on the character you want — the dashed box shows how much space the run takes.
  3. Paste it into the destination. Nothing will appear, which is the point; check the field length or cursor position to confirm it landed.
  4. If it vanishes, try another character. That destination strips the one you chose; Hangul Filler and Braille Blank survive the most filters.

Invisible text FAQ

What exactly is invisible text?

A character that a font draws as nothing, or as blank space, while still counting as a character. A normal space often does not work, because most platforms trim leading and trailing spaces and collapse repeats. The characters on this page are not spaces, so they survive that trimming — which is what makes an empty message or a blank username possible.

Which invisible character should I use?

Start with the Hangul Filler (U+3164) — it is accepted in the widest range of usernames, bios and chat boxes. If a site rejects it, try the Braille Pattern Blank (U+2800), which many games accept. The zero-width characters are a different tool: they take up no width at all, so use them to split or hide text rather than to create visible gaps.

How do I send an empty message on Discord or WhatsApp?

Copy one or two Hangul Fillers from the tool above and send that as the whole message. Discord, WhatsApp, Telegram and most chat apps see a non-empty string and send it, but nothing is drawn. Be aware that Discord has rate limits and server rules about spam — a wall of blank messages is a quick way to get muted.

Can I make a blank username?

Sometimes. Games and platforms vary: some accept the Hangul Filler outright, some strip it, and some ban accounts for impersonation if the name is indistinguishable from nothing. Check the platform's rules first, and never use a blank name to imitate a moderator or another player.

What is the difference between zero-width characters and the blank ones?

Zero-width characters (U+200B, U+200C, U+200D, U+FEFF) occupy no horizontal space at all — they sit between letters without showing a gap, which is how they get used for invisible separators and watermarks. The blank characters (U+3164, U+2800, U+00A0, U+3000) do take up width; they look like a space but cannot be trimmed as easily. They come from the General Punctuation and CJK blocks respectively.

Why does my invisible text disappear when I paste it?

Some forms strip characters they do not recognise, and some editors normalise zero-width characters out automatically. Nothing is wrong with the copy — the destination removed it. Try a different character from the list, or a larger count, before assuming it failed.

Yes. Every character is free to copy, there is no account, and nothing you copy is recorded.
