Underline styles this underline text generator produces

All seven results come from the Combining Diacritical Marks block, which Unicode designed for marks that attach to the character before them. Because the mark travels with the letter, the underline cannot be stripped out the way bold or italic formatting is. The table shows exactly which code point each style uses.

Underline text generator FAQ

Is this a real underline or just a font?

Neither — it is a combining character. Each letter you type is followed by an invisible mark that your device draws underneath it, so the underline is part of the text string itself. That is why it survives copy and paste into apps with no formatting toolbar, and why it is not a font you have to install.

Why does the line break between words?

The default style leaves spaces unmarked, so the rule stops at each gap. Pick the Continuous underline result instead — it marks the spaces too, giving one unbroken line across the whole phrase.

Does underlined text work on Instagram, TikTok and Discord?

Yes on all three, and on X/Twitter, Facebook, WhatsApp, Telegram, Reddit, Steam and most games. Discord renders combining marks in messages, nicknames and status; note that Discord also has its own __underline__ markdown, which is cleaner for ordinary messages and is the better choice when you are just chatting.

Will it look the same on every device?

Mostly. Combining marks are positioned by the font, so the line can sit slightly higher or lower on iOS than on Android or Windows, and letters with descenders (g, p, y) sometimes touch it. Paste a short test into the app you plan to use before committing it to a bio or a name.

Does underlined text count as more characters?

Yes. Every visible character carries one extra invisible mark, so a 20-character phrase becomes 40 code points. Fields with a strict limit — Instagram names, Twitter bios — will fill up twice as fast.

Can screen readers and search engines read it?

Screen readers usually read the base letters and ignore the marks, so the text stays understandable. Search engines, however, treat the combined characters as different from plain letters, so never underline a page title, a product name or anything people need to find by searching.

Is the underline text generator free?

Yes. It runs entirely in your browser, needs no account, and nothing you type is ever sent to a server.
