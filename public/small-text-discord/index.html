How to Make Small Text in Discord with -# Subtext

Discord added a native small text format called subtext in July 2024. It is the opposite of a heading: the line renders in a smaller, dimmed font, which is exactly what you want for footnotes, disclaimers and asides. No bot, no Nitro and no generator needed. If you have been looking up how to make small text in Discord, this is the answer Discord ships itself.

  1. Start a new line in the message box. Press Shift + Enter if you are adding the line under something you already typed.
  2. Type a hyphen, a hash and a space — that is -# followed by one space.
  3. Write your text on the same line, for example -# not an official announcement.
  4. Send the message. Discord strips the -# and renders the rest of the line small and grey.

Three rules decide whether it works. The -# has to be the very first thing on the line, the space after the hash is required, and every line you want shrunk needs its own -# — subtext does not carry over to the next line. You can still nest other formatting inside it, so -# **read the rules** gives you small bold text. The same syntax works in the desktop app, the browser and the mobile apps, and it is documented in Discord's own markdown formatting guide.

One limit is worth knowing up front: subtext is message markdown, so it renders only inside messages. Typing -# into a username, a nickname or a channel name just shows the characters literally. For those fields you need the Unicode route below.

How to Make Text Small in Discord on Mobile

How to make text small in Discord on a phone is the same question with the same answer: on iOS and Android the syntax is identical — there is simply no toolbar button for it, so you type -# by hand. Two things trip people up on a phone keyboard. Autocorrect likes to capitalise the first word and sometimes inserts a second space after the hash, and tapping the middle of an existing line puts the cursor past the start, so the prefix lands in the wrong place. Tap to the far left of the line first, then type the prefix.

For tiny Unicode text on mobile, use the generator at the top of this page, tap Copy, then long-press any Discord field and choose Paste. Because the result is plain characters and not formatting, it pastes cleanly into the message box, your display name or your status.

Where Small Text Works in Discord

Discord treats markdown and characters very differently depending on the field, and this is where most guides get vague. Markdown renders only where Discord parses messages; Unicode characters are just text, so they go almost anywhere — with one hard exception.

The username row is the one that surprises people. Since Discord retired discriminators, your unique handle is restricted to lowercase Latin letters, digits, underscores and periods, so no generator output will ever be accepted there. Put the styled version in your display name instead — it is what everyone actually sees next to your messages.

Subtext or Unicode Small Text in Discord

These two methods are not competing so much as covering different ground. Pick by where the text has to live and who has to read it.

Native formatting, so it stays searchable, copies as normal words and is read correctly by screen readers. It is limited to messages and to a single smaller size, and it always renders grey.

A practical rule: anything a person needs to find later — a rule, a link title, a pinned note — should use subtext or plain text. Anything decorative, like a nickname or a category divider, is where the generator earns its place. Small Text Not Working in Discord

Almost every report of broken subtext comes down to one of these, in rough order of how often it happens:

  1. Something sits before the prefix. A space, a quote marker or an emoji ahead of -# cancels it. The prefix must open the line.
  2. The space is missing. -#text stays as literal characters; -# text renders.
  3. You are inside a code block. Backticks tell Discord to print formatting characters instead of applying them, so nothing shrinks.
  4. You are typing in the wrong field. Markdown never renders in usernames, nicknames, channel names or server settings — only in messages.
  5. Boxes instead of letters. That is a missing glyph on an old device or font, and it affects Unicode small text rather than subtext. Small caps is the safest style to fall back to, and the small text generator home page shows every style side by side so you can compare them.

Small Text Discord FAQ

What is the small text command in Discord?

There is no slash command for it. Discord uses markdown instead: type -# and a space at the start of a line, then your text, and the line is sent in a smaller, dimmed font. It is called subtext and it works on desktop, browser and mobile.

How do I get small text in a Discord username?

You cannot. Your unique username only accepts lowercase letters, numbers, underscores and periods. Paste the generated small caps or tiny text into your display name or a per-server nickname instead — both accept Unicode and both are what other members see.

Can I make small text bold or italic in Discord?

Yes, with subtext. Nest the usual markdown inside the line, for example -# **bold subtext** or -# *italic subtext*. Unicode small text cannot be bolded, because Discord has no bold variants of those miniature characters.

Do backticks make text small in Discord?

No. Backticks switch the text to a monospace code style at the same size, and they also stop other formatting from being applied. If a guide tells you to use `text` for small text, it is out of date.

Does small text work in Discord channel names?

Unicode small text does. Channel names accept the characters, though Discord lowercases ordinary letters and converts spaces into dashes, so check the result before saving. Subtext markdown does not work there.

Will tiny text get me banned or flagged?

No. These are ordinary characters and Discord's own subtext is a documented feature. The only real risk is readability — servers sometimes ask members to keep nicknames legible, and moderators cannot search for text written in Unicode look-alikes.

Is this small text Discord generator free?

Yes. It is free, needs no account, and the conversion runs entirely in your browser, so nothing you type is sent to a server.
